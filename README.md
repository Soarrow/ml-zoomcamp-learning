# ML Zoomcamp Learning

My work following the [Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp)
by [DataTalks.Club](https://datatalks.club/) — a free, hands-on course on building,
evaluating, and deploying machine learning systems.

## Environment

Work is done primarily in a GitHub Codespace. To set it up:

```sh
pip install -r requirements.txt
```
